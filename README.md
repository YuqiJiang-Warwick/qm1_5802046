# QM1_5802046

## Gender Pay Gap Exercise

This repository contains the materials for the gender pay gap exercise. The goal is to explore, analyse, and present evidence about pay differences between genders using a simple data-driven workflow.

### Project overview

The exercise is designed to help students:

- understand how pay data can be cleaned and structured;
- compare compensation across gender groups;
- identify patterns, trends, and possible disparities;
- communicate findings clearly through analysis and visualisation.

### Repository contents

- `README.md` — project summary and usage notes
- `gender_pay_gap_exercise` — working file for the exercise

### Suggested workflow

1. Review the exercise instructions and dataset.
2. Clean and validate the data.
3. Compare pay by gender or related variables.
4. Generate charts or summary statistics.
5. Write short conclusions based on the evidence.

### Tools and technology

This type of analysis is typically completed with:

- Python
- pandas
- NumPy
- matplotlib or seaborn
- Jupyter Notebook

### Example setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install pandas numpy matplotlib seaborn jupyterlab
```
